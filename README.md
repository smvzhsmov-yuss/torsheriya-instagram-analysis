# Instagram Engagement Analysis
This project analyzes Instagram engagement data for Torsheriya, a small business specializing in unique handmade lamps. The goal was to identify which types of posts generated the highest engagement and determine the most effective times to publish content.

Tools Used:
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

Analysis
I analyzed social media performance by:
- Calculating total engagement for Instagram posts.
- Identifying the 10 posts with the highest engagement.
- Visualizing engagement using bar and line chart
  
Key Findings
- Posts featuring both a person and the product generated the highest engagement.
- The strongest posting window in the analyzed dataset was between 7 PM and 10 PM.
